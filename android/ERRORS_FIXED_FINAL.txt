  TECHNICAL EXPLANATION:
═══════════════════════════════════════════════════════════════

In Kotlin:
- `private` = visible only in the same file
- `internal` = visible across files in the same module
- `public` = visible everywhere (default for Composables)

We had helper functions marked `private` in CrowdDensityMapScreen.kt
but they were being called from CrowdDensityMapScreenWithViewModel.kt
(different file).

Solution: Changed to `internal` so they're accessible within the
same module (app module) but not outside it.
