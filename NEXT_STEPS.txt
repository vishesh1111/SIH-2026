=====================================================================
  TROUBLESHOOTING
=====================================================================

Map not loading?
→ Check local.properties has: MAPS_API_KEY=your_key
→ Enable Maps SDK in Google Cloud Console

Build errors?
→ ./gradlew clean build
→ Restart Android Studio

GPS points not visible?
→ Zoom to level 17-18
→ Tap recenter button (📍)
